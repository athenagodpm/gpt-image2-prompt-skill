# GPT Image 2 Prompt 框架参考

## 单次出图标准结构

```
[主体] — [核心场景] — [1-2个辅助元素]。
[风格/氛围] — [光影] — [构图]。
[弱化补丁]
```

| 模块 | 作用 | 原则 |
|---|---|---|
| **主体** | 视觉核心 | 1个，不超过2个 |
| **核心场景** | 在哪里，什么氛围 | 一句话讲清 |
| **辅助元素** | 只留最有必要的 | 1-2个，不能多 |
| **风格/氛围** | 整体视觉调性 | 单一风格，不混搭 |
| **光影** | 画面层次感 | 用"柔和的"替代"戏剧性的" |
| **构图** | 视觉重心 | 简洁明确 |
| **弱化补丁** | ⭐ 降噪关键 | 放在 prompt 最末尾 |

## Prompt 精简准则

每句话问自己：**这是必要的吗？**

| 准则 | 详解 |
|---|---|
| 1 个主体 | 最多 2 个，不然互相抢戏 |
| 1 个核心场景 | 不要同时出现"海边"+"雪山"+"都市" |
| 1-2 个辅助元素 | 不是购物清单 |
| 1 个风格 | "动漫+水墨+赛博朋克" = 哪个都做不好 |
| 1 个光源 | 不要"阳光+霓虹+烛光"同时出现 |
| 检查矛盾 | "雨天"+"蓝天白云"不能共存，"体积光"+"阴天"不成立 |
| 去掉脏词 | masterpiece, best quality, ultra detailed 对 GPT Image 2 弊大于利 |

## 推荐词库

| 类别 | 推荐用词 |
|---|---|
| 细节控制 | 弱化细节、简化质感、克制刻画、干净简洁 |
| 高级感 | 干净高级、留白、统一笔触、纯粹 |
| 光影 | 柔和光影、漫反射、自然光、柔光、散射光 |
| 构图 | 极简构图、负空间、平衡构图、留白 |
| 人物 | 自然姿势、细腻但不过度刻画、皮肤柔和 |
| 后期感 | 电影感色彩分级、柔和色调、低饱和 |

## 避免用词（脏图诱因）

| 类别 | 避开的词 |
|---|---|
| 极端细节 | 超现实细节、毛孔可见、极致写实、每一处纹理、ultra detailed、masterpiece |
| 强光影 | 戏剧性强光、volumetric light（容易过曝）、强对比 |
| 杂糅元素 | 同时塞多个材质/质感/光效要求 |
| 过载指令 | 一口气列出 8-10 个"需要" |

## 通用弱化补丁

| 风格 | 弱化补丁 |
|---|---|
| 通用/写实 | "整体画面弱化细节，干净高级感，柔和光影，控制噪点" |
| 极简/留白 | "极简构图，大量留白，笔触统一，抑制过曝和颗粒感" |
| 极繁 | "细节丰富但渲染干净，密集但有层次，控制噪点" |
| 动漫 | "干净的线条，无噪点无颗粒，画面纯净" |
| 产品/电商 | "干净的产品质感，柔和光影，无噪点" |

## 多轮迭代工作流

```
Round 1: 宽泛 prompt → 确定构图/氛围/主体位置
              ↓ 满意
Round 2: 保留 R1 框架，加少量关键细节
              ↓ 满意
Round 3+: 逐步微调，每次只改 1-2 个方面
              ↓ 脏了？
回退到上一个干净的版本，重新出发
```

每次迭代做两件事：
1. 保留核心框架（主体+场景+弱化补丁）不动
2. 只在一个维度上改动（要么调光影，要么加一个元素）

### 脏图处理

| 脏的程度 | 处理方式 |
|---|---|
| 轻微脏（边缘发糊、暗部噪点） | 加弱化补丁重跑 |
| 中度脏（头发结块、皮肤颗粒） | 回退到上一个干净版本重新加细节 |
| 重度脏（整体灰蒙蒙、细节打架） | 放弃迭代，从头生成基础图 |
| 改多轮仍不满意 | 导出到 Photoshop 兜底 |

## Prompt 老化处理

当同一主题生了很多张后，GPT Image 2 注意力下降：
1. 重新写一个新的 prompt（用不同句式表达同一内容）
2. 换风格描述词
3. 清空上下文，在新对话里生成
